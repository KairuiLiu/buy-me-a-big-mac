# Buy Me a Big Mac 🍔

把一句「谢谢你的开源」，变成开发者下一顿好好吃的饭。

一个免费的开源赞助工具。给自己或 GitHub 项目创建专属赞助页，让支持者用「请你吃一餐」的方式表达感谢。

[创建我的赞助页](https://buy-me-a-big-mac.liukairui.me/#create)

## 能做什么

- **创建专属赞助页**：支持个人和 GitHub 项目，选好附近餐厅就能分享给社区。
- **用一餐表达感谢**：支持者按实时菜单搭配餐品，获得参考赞助金额，再留下一句祝福。
- **通过爱发电收款**：支持者在爱发电完成赞助，作者自行安排什么时候享用这一餐。
- **送上一张感谢小票**：开启付款通知后，支持者付款成功可收到带动画的感谢小票。
- **把按钮放进 README 或网站**：提供简体中文、繁體中文、粤语简体、粵語繁體和 English 五种按钮。

## 开始使用

填写名字或项目地址 → 选择附近餐厅 → 填写爱发电信息 → 分享赞助链接或按钮。
